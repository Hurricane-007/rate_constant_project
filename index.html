First-Order Kinetics (−rA = k·CA)

For an isothermal, constant-density first-order reaction:

Plug Flow Reactor (PFR):
τP = −(1/k) · ln(CA/CA0) = −(1/k) · ln(x)
⟹ k·τP = −ln(x)
N Equal CSTRs in Series:
For each stage i: CA(i-1) − CAi = k · τ_stage · CAi ⟹ CA(i-1) / CAi = 1 + k·τN/N
Across N stages: CA0 / CAN = (1 + k·τN/N)^N ⟹ x = CAN/CA0 = (1 + k·τN/N)^(-N)
Rearranging: k·τN = N · [x^(-1/N) − 1]
Predicted Ratio: y_pred = τN / τP = N · [x^(-1/N) − 1] / [−ln(x)]

Second-Order Kinetics (−rA = k·CA²)

For an isothermal, constant-density second-order reaction:

Plug Flow Reactor (PFR):
k·CA0·τP = (CA0 / CA) − 1 = (1/x) − 1
N Equal CSTRs in Series:
Define β = k·CA0·τ_stage = k·CA0·τN / N.
Stage balance: c_(i-1) = c_i + β·(c_i)² ⟹ c_i = 2·c_(i-1) / [1 + √(1 + 4·β·c_(i-1))]
Given outlet ratio x = c_N, β is solved numerically by bisection.
Then k·CA0·τN = N · β.
Predicted Ratio: y_pred = τN / τP = (N · β) / [(1/x) − 1]

Key Chemical Engineering Insights:

  • Why τN / τP ≥ 1: A CSTR operates at the lowest reactant concentration (the exit concentration), minimizing reaction rate and requiring a larger volume. A PFR maintains high reactant concentration along its length.
  • PFR Limit (N → ∞): As the number of mixed tanks in series increases, backmixing decreases and the fluid behavior approaches plug flow, with τN/τP → 1.0.
  • Higher Reaction Order Amplifies Volume Differences: Second-order reactions are even more sensitive to backmixing than first-order reactions; thus, a single CSTR requires a substantially larger volume for second-order reactions at high conversions.
